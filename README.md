# Medical AI

This repository contains code for two research projects completed at the **Doheny Image Analysis Laboratory**, **Doheny Eye Institute**.

Each subfolder corresponds to a separate paper:

- **Sliding-Window-Transformer-CNNs-for-Predicting-Geographic-Atrophy-Progression**  
  A hybrid CNN–Transformer model for forecasting longitudinal Geographic Atrophy (GA) growth in AMD using structured temporal attention.

- **Model-Distillation-for-Segmentation-of-the-Foveal-Avascular-Zone**  
  A knowledge distillation framework for FAZ segmentation in OCTA images, designed to improve generalization across multiple retinal diseases.
